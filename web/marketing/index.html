CivicCast Lab
Private evaluation

For community stations

Put local programming on air.

CivicCast Lab is a private evaluation build for civic broadcasters who need council meetings, video podcasts and scheduled programming to reach cable, the station website and optional YouTube — with channels programmed independently.

Evaluation build v0.1.0.12 Read the user manual
Programming

Build a schedule that belongs to your community.

Carry a council meeting live on one channel while a recorded interview airs on another. Import a show, set its start time, and schedule the full program.

Operators can take an armed live source and hand the channel back to its schedule when the event ends.

Distribution

One operation. Several destinations.

CivicCast Lab targets cable with MPEG-TS, an independent HLS station website and optional YouTube RTMPS. The station sends each channel’s on-air program to its configured destinations. The website works independently of YouTube.
