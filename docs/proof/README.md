# Proof-record interpretation

Files in this directory are immutable historical records for specific source commits and installed
candidates. They must be read with their recorded candidate identity and must never be combined
across commits to manufacture an all-up result.

Earlier records refer to one-station-week and three-station-week gates. The inherited
[Townlight assessment](../../PROJECT_STATUS.md#retired-townlight-beta-gate) describes the later
four-to-eight-hour beta gate. See the [v0.1.0.14 prerelease](https://github.com/scottconverse/civiccast-lite/releases/tag/v0.1.0.14)
and the [current operator manual](../USER-MANUAL.md) for CivicCast Lite.
